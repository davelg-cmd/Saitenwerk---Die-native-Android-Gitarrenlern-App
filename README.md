🎸 Saitenwerk – Die native Android-Gitarrenlern-App

Saitenwerk ist eine moderne, vollständig native Android-App für Gitarristen – vom Anfänger bis zum fortgeschrittenen Spieler. Mit integriertem Gitarrenstimmgerät, umfangreicher Akkordbibliothek, Liederbuch, interaktivem Lernstudio und einem persönlichen Lernpfad vereint Saitenwerk alles, was du zum Lernen, Üben und Spielen brauchst.

Der Fokus liegt auf einer intuitiven Bedienung, einem hochwertigen Design, Offline-Funktionalität und kontinuierlichem Lernfortschritt.

Entwickelt mit Leidenschaft von David Elger.
